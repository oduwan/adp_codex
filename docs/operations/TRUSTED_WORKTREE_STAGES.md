## Trust and stages

The selected dedicated local product worktree and already admitted local history
are trusted under cooperative ADP single-writer control. Hypothetical malicious
same-UID changes during that ownership are outside this model, **not security
tests credited PASS**. Untrusted enrollment paths, GitHub, credentials, current
canonical M1/M2 state, deadlines, explicit revocation and unknown effects do not
inherit that trust. A stopped old result is not a new independent review.
